# QCE 2026 TUT::QHPC::QSIMU::297 agenda website

Agenda website for the [QCE 2026 — IEEE Quantum Week](https://qce.quantum.ieee.org/2026/) tutorial
**Deploying fermionic simulations on quantum-centric supercomputers**
(`TUT::QHPC::QSIMU::297`).

## Local preview

Requires Ruby and Bundler.

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
